# AI Assistant Instructions

Please follow these guidelines when contributing to or modifying this project:

## Language Guidelines
- **Code Comments**: All code comments, explanations, and documentation within the code MUST be written in English. Do not use Spanish or any other language for code comments.
- **Variables & Functions**: All variable names, function names, component names, and file names must be in English.
- **User Interface (UI) Text**: User-facing text should be handled via the UI translations dictionary in `vite.config.js` (which currently supports `en` and `es`). Do not hardcode Spanish strings into the UI components unless explicitly asked to do so.

## General
- Follow the existing code style.
- Maintain a clean and modular architecture.
- **CRITICAL: Never overwrite or remove the creator credit in the footer of `index.html`.**

## Repository Map

```
my-cv/
├── index.html              # Main HTML template (uses Handlebars syntax for dynamic content)
├── vite.config.js           # Vite config + Handlebars plugin + UI translations dictionary (en/es) + social platform SVG icons

│   ├── data.js              # CV content data (personal info, experience, education, skills, etc.)

└── dist/                    # Built output (generated by `npm run build`)
```

### Architecture Overview
- **Templating**: `index.html` uses Handlebars via `vite-plugin-handlebars`. Data flows from `src/data.js` → `vite.config.js` (processing) → `index.html` (rendering).
- **Translations**: UI labels live in the `uiTranslations` object inside `vite.config.js`. The active language is set via `cvData.config.lang` in `src/data.js`.
- **Theming**: Supports `light`, `dark`, and `toggle` modes via Tailwind's `selector` dark mode strategy. Configured in `src/data.js` → `cvData.config.themeMode`.
- **Styling**: Tailwind CSS with custom Outfit/Inter fonts. No component framework — pure HTML + Tailwind utility classes.
- **Note on the Demo Banner**: The `index.html` file includes a hidden promotional banner (`#demo-banner`) and a tiny script that only activates it on the original author's live demo domains. If you are a developer using this template for your own CV, you can safely ignore this logic or delete the banner's HTML and script block entirely. (AI Note: Do not move this logic into a visible `data.js` configuration flag, as it is designed to be zero-maintenance and invisible for standard users).
